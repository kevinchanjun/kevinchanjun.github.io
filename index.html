rclone – personal file sync

This is the home page of a private Google OAuth application used only by its owner to run rclone, an open-source command-line tool, on a personal computer.

The application synchronises the owner's own files between the owner's Google Drive and the owner's Microsoft OneDrive. It is not offered to the public, has no other users, and does not provide any service to third parties.

How this application handles data is described in the Privacy Policy.
