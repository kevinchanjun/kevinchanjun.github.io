Privacy Policy

Applies to the private OAuth application "rclone" described on the home page. Last updated: September 30, 2026.

Who uses this application

This application is used only by its owner, on the owner's own computer, to access the owner's own Google account. It has no other users.

What data is accessed

The application requests the Google Drive scope (https://www.googleapis.com/auth/drive) so that rclone can list, read, create, update and delete files in the owner's Google Drive. It is used solely to synchronise the owner's files between Google Drive and the owner's Microsoft OneDrive.

How data is used and stored

Files are transferred directly between the owner's computer, Google Drive and Microsoft OneDrive. OAuth tokens are stored only in the rclone configuration file on the owner's computer. No data is collected, stored or processed on any server operated for this application.

Sharing

No data obtained through Google APIs is sold, shared with, or transferred to any third party.

AI and machine learning

No data obtained through Google APIs is used to develop, improve or train generalised artificial intelligence or machine learning models.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
